# Subterranean Gate — source art drop

Upload the Subterranean Gate Token illustration here so it can be cropped into the
two hex halves used on the board.

- **File name:** `source.png` (or `source.jpg` / `source.webp`)
- **What it is:** the two-hex "Subterranean Gate Token" illustration (the skull
  cave-mouth half + the other half, side by side).

Once the file is committed here, the crop script regenerates:

- `public/assets/board/tokens/subterranean-gate-surface.webp` — the half shown on
  the **Surface** tile (the gate / cave-mouth you descend into).
- `public/assets/board/tokens/subterranean-gate-underground.webp` — the half shown
  on the **Underground** tile (the entrance / path up).
