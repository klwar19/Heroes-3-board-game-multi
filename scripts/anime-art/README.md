# Anime art production sources

This directory keeps the anime mod's editable visual sources separate from
runtime assets.

- `raw/` contains full-resolution, frame-free generated masters. No title,
  stat, rule text, icon, or border is baked into these images.
- `editable/` contains layered SVG card sources. Open them in Inkscape,
  Illustrator, Affinity Designer, or another SVG editor. The illustration is a
  linked raster layer; the frame and all typography remain editable.
- `previews/` contains flattened WebP art proofs generated by the compositor.
- `archive/` retains superseded full-resolution alternatives that may still be
  useful for future roster revisions; the manifest never treats them as active.
- `refs/` is gitignored. Downloaded or user-supplied identity references are
  research inputs only and must never be copied into `public/` or committed.

Build the current proofs with:

```sh
node scripts/build-anime-cards.mjs
```

Monster Girl Quest uses source-verified, fail-closed production contracts rather
than proof placeholders:

```sh
node scripts/build-mgq-unit-cards.mjs --check-contract
node scripts/build-mgq-art.mjs --check-contract
```

See `docs/mgq-art.md`. Approved masters go only at the paths printed by each
script's `--list-masters`; the compositors will not invent a missing image.

The current Fuyuki and Azure Breeze cards are visual proofs only. Fuyuki uses a
violet nocturne frame with a left stat rail. Azure Breeze deliberately follows
the original board game's unit-card layout: title bar, four stacked left stats,
portrait, type mark, `# FEW` / `# PACK` band, and bottom rules panel. Its linked
image-generated frame changes only the leather, jade inlay and corner details;
text, stats, icons and rules stay editable SVG. Both suites stay out of
`public/assets` until their definitions and effects meet `CLAUDE.md`.
